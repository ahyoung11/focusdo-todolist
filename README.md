# FocusDo - 스마트 할 일 관리 (To Do List)

PRD(제품 요구사항 정의서)에 명시된 기능과 4개 화면 구조를 완벽히 구현한 모던 웹 애플리케이션입니다.

---

## 🚀 지금 바로 실행하는 방법 (Zero Install)

컴퓨터에 Node.js나 추가 프로그램 설치 없이, **웹 브라우저에서 즉시 실행**할 수 있습니다!

1. 파일 탐색기에서 현재 폴더(`todolist`)를 엽니다.
2. **`index.html`** 파일을 더블 클릭하거나, Chrome / Edge 등 웹 브라우저 창으로 드래그합니다.
3. 브라우저에서 바로 모든 기능을 사용하실 수 있습니다. (모든 데이터는 브라우저 LocalStorage에 안전하게 자동 저장됩니다.)

---

## 📱 구현된 4개 화면 (Screen Overview)

1. **[화면 1] 메인 대시보드 (Main Dashboard)**
   - **사이드바**: 오늘 할 일 / 중요한 일(★) / 예정된 일 / 전체 목록 / 완료된 항목 스마트 필터
   - **카테고리 칩**: 업무, 개인, 공부, 쇼핑 등 컬러 라벨별 분류
   - **빠른 추가(Quick Input)**: 한 줄 입력 및 마감일/우선순위 지정 후 `Enter` 즉시 등록
   - **태스크 리스트**: 완료 토글 체크박스, 중요 표시, D-Day/마감일 뱃지, 실시간 정렬 및 검색
   - **달성률 프로그레스 바**: 오늘의 완료율(%) 시각화

2. **[화면 2] 태스크 상세/편집 드로어 (Detail Drawer)**
   - 태스크 클릭 시 우측에서 슬라이드로 열리는 세부 설정 패널
   - 제목 및 마크다운 메모/설명(Description) 인라인 수정
   - 하위 체크리스트(Sub-tasks) 추가 및 완료 체크
   - 마감일, 우선순위(🔴/🟡/🔵), 카테고리 즉각 변경

3. **[화면 3] 카테고리 관리 모달 (Category Modal)**
   - 신규 카테고리 추가 및 컬러 픽커
   - 기존 카테고리 목록 관리 및 삭제

4. **[화면 4] 환경설정 및 데이터 관리 (Settings Modal)**
   - **라이트 모드 / 다크 모드** 테마 원클릭 전환
   - **JSON 데이터 백업**: 클릭 한 번으로 내 모든 할 일 데이터를 파일(`focusdo_backup.json`)로 다운로드
   - **백업 파일 복원**: 저장해둔 JSON 파일을 불러와 데이터 복구
   - **데이터 초기화**: 온보딩 기본 상태로 리셋

---

## 🛠️ 추후 Node.js 설치 시 번들러 실행 방법 (선택 사항)

Node.js 환경에서 Vite 개발 서버로 실행하고 싶을 경우:

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로컬 개발 서버 실행 (http://localhost:5173)
npm run dev

# 3. 배포용 빌드
npm run build
```
